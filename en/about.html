Graded Assignment 1 · Web Programming Fundamentals · PUCPR

Made by Gustavo Cervejera, a Systems Analysis and Development student. Built with plain HTML, CSS and JavaScript, no frameworks, and it runs straight from a folder on your computer.

Files

index.html · home page: résumé and projects on a single page
form.html · contact form (portuguese only)
formAction.html · receives the data sent via GET
projeto-*.html · one page per project
projetos.html · all projects, with a filter by type
estudos-*.html · one college assignment per page
about.html · this page
css/ · style.css
script/ · index.js, projetos.js, projeto.js, estudos.js, form.js, action.js, about.js, rodape.js
img/ · favicon.svg (tab icon), projetos/ (covers and screens) and estudos/ (assignment screenshots)

How it was made

HTML

  • The same menu and footer on every page
  • A form with required, pattern and several input types
  • Tables, lists and relative paths for every file

CSS

  • A single external file, with reusable classes (coluna, bloco, faixa, campo...)
  • Pseudo-classes :hover, :focus, :nth-child and a layout for phone screens

JavaScript

  • index.js: roles and certifications that open and close, a timeline that follows the scroll, and project entrance animations
  • projetos.js: filter on the projects page
  • projeto.js: activity chart for each project
  • form.js: regex validation, phone mask and error messages
  • action.js: reads the data that arrived in the URL via GET
  • rodape.js: works out how many days ago the site was updated
