Este site

Atividade Somativa 1 · Fundamentos de Programação Web · PUCPR

Feito por Gustavo Cervejera, aluno de Análise e Desenvolvimento de Sistemas. Construído só com HTML, CSS e JavaScript, sem frameworks, e funciona direto de uma pasta do computador.

Arquivos

index.html · página inicial: currículo e projetos numa página só
form.html · formulário de contato
formAction.html · recebe os dados enviados por GET
projeto-*.html · uma página por projeto
projetos.html · todos os projetos, com filtro por tipo
estudos-*.html · um trabalho da faculdade por página
about.html · esta página
css/ · style.css
script/ · index.js, projetos.js, projeto.js, estudos.js, form.js, action.js, about.js, rodape.js
img/ · favicon.svg (ícone da aba), projetos/ (capas e telas) e estudos/ (prints dos trabalhos)

Como foi feito

HTML

  • O mesmo menu e o mesmo rodapé em todas as páginas
  • Formulário com required, pattern e vários tipos de input
  • Tabela, listas e caminhos relativos para todos os arquivos

CSS

  • Um único arquivo externo, com classes reaproveitadas (coluna, bloco, faixa, campo...)
  • Pseudoclasses :hover, :focus, :nth-child e ajuste para telas de celular

JavaScript

  • index.js: cargos e certificações que abrem e fecham, linha do tempo que acompanha a rolagem e entrada dos projetos
  • projetos.js: filtro da página de projetos
  • projeto.js: gráfico de atividade de cada projeto
  • form.js: validação com regex, máscara de celular e mensagens de erro
  • action.js: lê os dados que chegaram na URL pelo método GET
  • rodape.js: calcula há quantos dias o site foi atualizado
